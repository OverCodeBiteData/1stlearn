# Geopolitical Voting & LIGHTCOIN App

This is a lightweight web-based app for voting on geopolitical questions, earning LIGHTCOIN cryptocurrency through local storage-based blockchain.

## Features
- Vote on geopolitical questions.
- Earn LIGHTCOIN for voting, sharing, and accurate predictions.
- Simple game: Earn extra if you pick the majority.
- Local blockchain to record all actions.
- Share to earn more coins.
- Export your blockchain for potential future conversion to real value.

## How to Use
1. Open `index.html` in a web browser (preferably on mobile for app-like feel).
2. Vote on the question.
3. Earn coins, play the game, share, and collect rewards.
4. Use "Export Blockchain" to view your transaction history.

## LIGHTCOIN
- LIGHTCOIN is created locally via a simple blockchain.
- All transactions (votes, rewards) are blocks in the chain.
- Export the JSON to potentially convert to real money in the future (requires external infrastructure).

Note: This is local only; to make it like a real blockchain, it would need peer-to-peer network, but this is lightest version.

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
